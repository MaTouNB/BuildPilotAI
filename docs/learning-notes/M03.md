# M03 学习笔记

## 查询链路

浏览器表单把筛选条件编码为 URL 查询参数，Vite 将 /api/v1 请求代理到 FastAPI。Pydantic 校验类型、范围和排序枚举，SQLAlchemy 用绑定参数查询 PostgreSQL；响应契约将 NUMERIC 金额转换为字符串，React 根据结果显示列表或明确状态。

page/page_size 只限制本页记录，total 是符合条件的全部数量。排序最后加 UUID 避免同名商品在相邻页随机重复。名称搜索把 %/_ 当作文字，不允许直接拼接 SQL。404 表示无可见规范商品，422 表示请求格式错误，503 表示服务暂时不可用。

## 页面状态和服务器状态

筛选输入、详情开关和页码是页面状态；商品、价格、源行是服务器状态。当前小型只读页面使用可取消请求 hook，没有引入额外缓存库；换筛选或重试时派生加载状态，旧请求取消并忽略其响应，避免较慢请求覆盖新结果。

has_price 只表示存在合法历史价，is_quotable 表示有明确审核的选价。缺价/未选价/冲突不是 USD 0；后续装机预算必须使用 selected_price_id 及快照，不能从列表取最低候选价。
