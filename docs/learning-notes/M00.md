# M00 学习笔记与练习

## 本阶段五个核心概念

1. Python 模块与虚拟环境：`app.main:app` 指 app/main.py 中名为 app 的对象。uv 将依赖装在 backend/.venv，使项目依赖与系统 Python 分开；uv.lock 固定依赖解析结果。
2. HTTP 路由：FastAPI 装饰器绑定 GET 路径。`/health` 返回 Pydantic 模型，由框架序列化为 JSON；200 表示请求成功。`/ready` 无法连接数据库时返回 503，页面据此显示未就绪。
3. React 状态与副作用：useState 存储页面状态；useEffect 发起网络检查。Promise.all 并行发起两次独立探测，AbortController 在超时或卸载时取消请求；active 标记防止旧请求覆盖新页面状态。
4. 容器、端口与卷：PostgreSQL 在容器内监听 5432，映射到本机 5433；命名卷保存数据库文件。容器 healthy 不等于应用已用正确凭据连接，所以还需要 `/ready` 的真实 SQL 探测。
5. 测试分层：pytest 的模拟连接测试验证成功/失败逻辑；Vitest 验证 UI 展示及重试；smoke 脚本连接真实 PostgreSQL；浏览器验收确认代理和真实页面。任一层不能替代其他层。

## 调用链

浏览器打开 5173 → React effect → GET /health 与 /ready → Vite 代理到 8000 → FastAPI → psycopg SELECT 1 → PostgreSQL → JSON → 页面显示两项状态。

密码从根目录私有 .env 读取，只进入后端和数据库容器；前端不需要密码。M00 没有模型调用、登录或装机数据。
