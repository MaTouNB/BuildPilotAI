# M05 学习笔记

认证回答“请求属于谁”，授权回答“这个身份能访问什么”。会话证明用户身份，tenant_member证明所选租户仍有效；Build仍需检查创建者，不能因为同租户就读取他人的方案。

随机opaque Cookie只由服务器解析，数据库保存其SHA-256而不是原令牌。退出删除服务器会话，因此复制旧Cookie也不能恢复访问。HttpOnly防脚本直接读凭证；SameSite/Origin与独立CSRF校验共同限制跨站写入。CSRF在内存中传递，不是身份声明，也不能代替会话。

幂等不代替授权。原请求已成功，也必须在重放时重新检查会话、成员和资源归属，否则撤销权限后会泄漏历史结果。客户端上传owner/tenant字段不能变成服务器身份。

本地开发密码随机生成，只写入600权限文件；公开仓库只含代码和合成测试。Demo到登录迁移不等于把旧数据交给第一个登录者，已有归属必须保留，迁移需要额外明确授权。

练习：同租户两人分别创建方案并复制UUID；用不同成员尝试切租户；退出后复制旧Cookie尝试读取；解释为什么这些检查必须发生在服务端。
