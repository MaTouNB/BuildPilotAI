## 手工复验

1. `make db-up && make db-migrate && make dev`，打开 http://127.0.0.1:5173/。
2. 用本地已有开发账号登录，选择其私人方案；添加/修改仍需 Diff 与确认。
3. 查看兼容报告。缺少组件/证据显示 UNKNOWN，展开规格查看出处；核对未覆盖项。
4. 点击重新检查，刷新页面；核对方案版本、报价快照不变。
5. 切换其他租户，确认看不到原私人方案；无身份直接访问报告应 401。

规格写入仅本地运维命令，没有开放 HTTP 审核权限。PENDING/REJECTED 不隐藏既有 APPROVED 记录；修正已批准错误需追加 APPROVED 版本并明确 supersedes_id，历史保留。当前不提供批量撤销/审核 UI。三规则均 PASS 也仅代表标称条件通过。
