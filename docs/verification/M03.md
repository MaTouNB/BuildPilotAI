## 变更与架构

- backend/app/catalog.py：只读查询服务，参数校验、稳定分页、文字搜索、已选价范围、分类、源批次、商品详情和分页历史价。
- backend/app/catalog_schemas.py：Pydantic 公共响应契约，保留金额字符串/null，排除私有审核字段。
- backend/app/main.py：注册目录路由、懒初始化引擎、服务关闭释放资源、请求 ID 与脱敏错误。
- frontend/src/Catalog.tsx/api.ts：目录筛选与详情抽屉；独立并行数据请求，8秒超时、取消和过期响应保护、加载/错误/空状态。
- frontend/src/EnvironmentPanel.tsx：保留环境探测，App 选择目录或环境页；继续使用已有 Ant Design，未增加依赖。
- tests/db/conftest.py：共用真实 PostgreSQL 随机隔离 schema，不清空业务数据。

## 手工验收

`make db-up && make db-migrate && make dev`，打开5173：先核对单用户标识和历史USD日期；尝试名称/类别/有价/报价状态筛选，查看详情与源行；断开数据库验证503和前端重试（测试后恢复）。新环境若未应用本地真实审核文件，应是空目录；不应混入合成 fixtures。

限制：没有登录、兼容规则、装机写操作、AI；详情证据最多100条，历史价格独立分页；价格范围只筛选已选价；刷新不持久化筛选状态。M03 不对数据集商用授权或当下市场价格作保证。
