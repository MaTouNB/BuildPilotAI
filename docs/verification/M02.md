## 手工验收

1. `make setup && make db-up && make db-migrate`。
2. 已有本地 M01 输出时运行 `make check-m02`，再运行 `make check-db`。
3. 按 README 运行 import_db --dry-run；确认不需要数据库连接也可校验。
4. 在 data/reviews/ 准备已核对的少量 source_record_key → UUID 映射，用 --review-map --apply 补充身份及选价。不要把 README 占位符当作真实审核文件。
5. SQL 通过 part_price.source_row_id 连接 raw_import_row，可看到具体 CSV、物理起止行和原始金额；未审核价格 part_id 为 NULL，不表示记录丢失。

## 限制与下一阶段

当前本地可信操作者 CLI，没有登录管理员流程；reviewed_by 是操作者声明，不是认证用户 ID。已成功入库的金额不因后续选价被改写，但 M04 装机价格快照尚未实现。兼容 pipeline 格式/规格变动不自动改规范商品；跨输入版本需要显式审核。进程被强制终止可能留下 RUNNING 尝试，重试可在锁释放后处理，尚无自动故障清理服务。

M03 前需要审核少量可靠真实条目，以建立可展示的规范目录。本轮不替操作者伪造审核，不推进配件 API。
