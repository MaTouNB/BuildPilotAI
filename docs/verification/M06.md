# M06 Mock 只读目录助手验收

日期：2026-10-15。用户明确选择「3：先用 Mock 模式完成本阶段」。本次验收仅覆盖模拟 Provider、真实工具/数据库和网页助手，不是付费模型或自然语言理解质量验收。OpenAI-compatible 实际 endpoint 适配器未实现，未读取或写入 API Key。

## 实现文件与范围

- backend/app/agent/provider.py：Provider 协议、分层系统提示、确定性 MockProvider，使用 LangChain AIMessage/ToolMessage。
- backend/app/agent/tools.py：StructuredTool 白名单 search_parts/get_part/get_reference_price；Pydantic 严格参数，独立只读数据库事务和原始行溯源。
- backend/app/agent/runtime.py：受限工具循环、超时、上下文/输出上限；报价内容由后端工具结果生成，不采信模型自报金额。
- backend/app/agent/routes.py：需要认证/CSRF 的 POST /api/v1/ai/chat；单进程用户/租户/全局频率及并发限制。
- backend/app/main.py、config.py、.env.example：接路由、no-store、请求体上限、mock-only 设置。
- backend/pyproject.toml、uv.lock：固定 langchain-core 1.6.10、langsmith 0.14.8 及传递依赖；外部 tracing 在调用作用域中强制关闭。
- frontend/src/CatalogAssistant.tsx、App.tsx、App.css、api.ts：懒加载助手、宽屏侧栏/窄屏流式布局、实际调用明细、来源卡片、取消/错误处理、身份切换清空结果。
- backend/tests/test_agent.py、tests/db/test_agent.py、frontend/src/tests/CatalogAssistant.test.tsx：单元、真实 PostgreSQL、界面回归。
- README、API/安全/路线图/修订、学习笔记、总手册同步。无需新迁移，不写聊天、方案、审核规格或报价表。

## 限制与下一阶段

- Mock 只支持有限型号/简单查询；不代表真实模型会正确选择工具，也不能自由对话。
- M06 不接私有方案工具、兼容工具、RAG、审批修改；只读目录工具没有私人数据权限。
- 不保存聊天；刷新页面、退出或切换租户会清空界面结果，没有多轮上下文或流式输出。
- 限流/并发是进程内保护，仅适用于当前单进程本地服务。多 worker/多实例前必须增加共享配额存储；进程重启会重置窗口。
- 实际 endpoint 适配器、费用/token 统计、真实模型能力评估待用户另行授权模型接入；没有宣称已测试。
- 下一阶段建议 M07 的持久化会话与上下文，继续可用 Mock；本次不实施。
